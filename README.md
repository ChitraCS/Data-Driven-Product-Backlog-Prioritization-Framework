# Data-Driven-Product-Backlog-Prioritization-Framework
Data-driven, multi-criteria framework for Agile product backlog prioritization. Compares MoSCoW, RICE, WSJF, Kano and AHP, and proposes a weighted scoring model (business value, customer impact, risk, compliance, effort). Includes practitioner survey analysis (Chi-Square, correlation, ranking). MBA research, SRM Institute, 2026.
